# Installation

The package requires Python 3.14 or newer and a SIMAR customer portal account. Python does not define an official LTS release; this project targets the latest stable version available at its initial development.

```shell
python -m pip install aquamatrix-simar
```

For development or installation directly from the source repository:

```shell
python -m pip install "git+https://github.com/OldemarJesus/aquamatrix-python-sdk.git"
```

The public package name is `aquamatrix-simar`; the Python import package is `aquamatrix_simar`.
